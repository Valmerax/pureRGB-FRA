Utilisez Floating IPS : https://github.com/Sir-Walrus/Flips/releases/latest 
ou un Patcher en ligne : https://www.marcrobledo.com/RomPatcher.js/
pour patcher la ROM anglaise de Pokemon Blue afin d'obtenir BleuPur ou VertPur. 
Pour RougePur, utilisez la ROM anglaise de Pokemon Red.

Téléchargez la dernière version de RougePur, VertPur ou BleuPur ici (fichiers de patch en bas de page):
https://github.com/Valmerax/purRVB/releases/latest
