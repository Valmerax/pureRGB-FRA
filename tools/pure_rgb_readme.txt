Utilisez Floating IPS : https://github.com/Sir-Walrus/Flips/releases/latest 
ou un Patcher en ligne : https://www.marcrobledo.com/RomPatcher.js/
pour patcher la ROM anglaise de Pokemon Blue afin d'obtenir BleuePure ou VertePure. 
Pour RougePure, utilisez la ROM anglaise de Pokemon Red.

Téléchargez la dernière version de RougePure, VertePure ou BleuePure ici (fichiers de patch en bas de page):
https://github.com/Valmerax/pureRGB-FRA/releases/latest
